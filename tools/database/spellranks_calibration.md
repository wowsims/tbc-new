# Spell rank calibration

Generated by `go test ./tools/database/ -run SpellRankCalibration -update`. Do not edit by hand.

Every hand-written rank row in the sim, compared against the value derived from the client DB.
This is the gate the generator has to pass before it may replace those tables.

## Rule

```
delta = max(0, min(70, MaxLevel > 0 ? MaxLevel : 70) - SpellLevels.SpellLevel)
base  = f32(EffectBasePoints + f32(delta * f32(EffectRealPointsPerLevel)))
min   = floor(base) + 1
max   = ceil(base)  + EffectDieSides
```

float32 throughout is load-bearing: the multiply in float64 breaks rows this gets right.
A coefficient within 5e-4 counts as a match - the hand tables write `0.429` for `0.428999990224838`.
